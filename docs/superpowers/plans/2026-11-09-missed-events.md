# Устранение воспроизводимых пропусков

Работа по числовым наблюдениям, без видео, обучения, новых зависимостей и
изменений контрактов или нормативных оснований. Проверки качества на реальных
трассах недоступны; синтетические тесты не заменяют precision/recall.

1. Восстановить независимость подтверждённого выхода от дублей одного PTS
   и позднего разрыва; после разрыва отсутствие снова неизвестно. Сохранить
   проверки наличных и присутствия других людей. Исправить требование двери
   для уже поддерживаемого relaxed-выхода через край.
2. Оценивать размер только по устойчивым участкам треков, наблюдаемым на данном PTS.
   Отделить поддержку raw-трека от подавления дублей для статистики/подсчёта.
3. Проверить точные границы времени при сдвиге PTS; разрешить только ошибку
   floating point, без допуска шага сэмплирования и без склейки реальных дыр.
4. Передавать определённого сценой кассира в правило посетителей. Подключить
   это правило в общий реестр и исключить молчаливый пропуск включённых кодов.
5. Для каждой причины сначала воспроизвести сбой тестом, затем исправить;
   добавить отрицательные сценарии, провести независимое ревью и полный check.
6. Обновить README/документацию с оставшимися ограничениями моделей и сигналов.
   После проверок создать новый коммит 19.10.2026 (+05:00), позже 10:43:15,
   влить fast-forward и запушить main, сверить SHA на GitHub.

## Проверено до полного шлюза

Все найденные пропуски воспроизведены до исправления. 140 целевых тестов
сцены/правил/реестра прошли. Независимое ревью дополнительно выявило перенос
статистики через постоянный фон и ошибочную подмену рамки кассира всей зоной;
добавлены регрессии, обе причины исправлены. Повторное ревью не обнаружило
блокирующих замечаний. Порог масштаба теперь локален по PTS, raw-поддержка
ID отделена от NMS-голосов. Типы изменённых модулей и тестов проверены.

## Полный шлюз

`uv run just check` прошёл: 933 Python-теста и 36 web-тестов; 6 пропусков
из-за отсутствия Torch и ограничений Windows (symlink/SIGSTOP). Ruff,
basedpyright, import-linter и проверки дрейфа схем прошли. Результаты на Mac
и реальных видео не измерялись. Нормативные основания, модели, зависимости
и замороженные контракты не изменялись.
