# ADR-0013. Публичный вход: именованный Cloudflare Tunnel — основной, Tailscale Funnel — резерв

> Назначение: зафиксировать, как жюри и проверяющие попадают на сервис, работающий на Mac за NAT.
> Владелец: S0 (документ); реализует S6 (`deploy/cloudflared/config.yml.tmpl`, `deploy/macos/launchd/kz.cashguard.tunnel.plist.tmpl`, [runbook_mac.md](../runbook_mac.md)). Статус: черновик v1, 17.10.2026.

## Статус

Принято. Открытый вопрос grill-me: есть ли домен для именованного туннеля (умолчание — купить дешёвый; если нет — Tailscale Funnel становится основным, и через него проверяются 5 параллельных загрузок по 29 МБ).

## Контекст

- FAQ 23: обязателен публичный URL. FAQ 13: жюри загружает видео удалённо. ТЗ §8: команда передаёт адрес UI, адрес API и ключ.
- Сервис работает на MacBook за NAT; сетью площадки команда не управляет.
- Загрузки ≈ 29 МБ, возможно 5 и больше одновременно.
- Cloudflare: лимит тела 100 МБ на бесплатном плане, таймаут origin 100 с.
- Quick tunnel (trycloudflare): адрес меняется при перезапуске, SSE не поддерживается.
- Площадка может блокировать UDP (порт 7844), на котором работает QUIC-транспорт cloudflared.
- Tailscale Funnel не требует домена, но его лимиты пропускной способности не документированы.
- Два коннектора на одном именованном туннеле балансируют нагрузку между собой.
- Время загрузки по каналу жюри входит в 300 с.
- Bot Fight Mode Cloudflare может блокировать curl.

## Решение

1. **Основной вход — именованный Cloudflare Tunnel на домене команды:**
   - `protocol: http2`;
   - ingress `http://127.0.0.1:8000` (не `localhost`), последнее правило — `http_status:404`;
   - metrics `127.0.0.1:20241`;
   - шаблон `deploy/cloudflared/config.yml.tmpl` (UUID туннеля подставляется при установке);
   - LaunchAgent `kz.cashguard.tunnel`: `cloudflared tunnel --config ~/.cloudflared/config.yml run`, KeepAlive.
2. **Настройки Cloudflare:** Bot Fight Mode выключен, Under Attack выключен, `/api` не кэшируется. Кадры отдаются с `Cache-Control: private` ([ADR-0008](0008-separate-ui-api.md)).
3. **Согласование таймаутов:** uvicorn `--timeout-keep-alive 100` больше 90 с keep-alive cloudflared к origin. POST отвечает сразу после записи файла, задолго до 100 с таймаута origin ([ADR-0004](0004-auth-before-body-streaming-upload.md)).
4. **Резерв — Tailscale Funnel**, работает одновременно: `tailscale funnel --bg 8000` отдаёт тот же origin со второго URL. Адрес сдаётся как резервный.
5. **Quick tunnel** — только для дымовых тестов P0. Жюри не отдаётся.
6. **Запрет:** не запускать второй коннектор на тот же именованный туннель, пока работает коннектор Mac. Резервный Docker-образ на Windows-ПК с RTX 3050 запускается только после остановки коннектора Mac.
7. **Наблюдение:** supervisor опрашивает metrics `/ready` cloudflared каждые 15 с; при сбое — лог и уведомление osascript. Упавший cloudflared перезапускает launchd.
8. Сервис слушает только `127.0.0.1`; IP клиента — из `CF-Connecting-IP`, доверие только от пира `127.0.0.1`.

## Рассмотренные альтернативы

| Альтернатива | Почему отклонена |
|---|---|
| Quick tunnel (trycloudflare) | Адрес меняется при перезапуске; нет SSE |
| ngrok free | Ещё одна внешняя зависимость без преимуществ перед именованным туннелем; ограничения бесплатного плана не проверялись |
| Проброс портов или публичный IP | Сетью площадки команда не управляет; Mac открывается в интернет напрямую |
| Reverse proxy на VPS | Лишняя машина, расходы и ещё одна точка отказа |

## Последствия

Плюсы:
- Стабильный адрес переживает перезапуски.
- Лимит 100 МБ покрывает видео ≈ 29 МБ.
- http2 обходит блокировки UDP.
- Резервный URL работает постоянно, переключение не требует действий.

Минусы и цена:
- Нужен домен (открытый вопрос).
- Лимиты Funnel не документированы.
- Через туннель идёт только трафик; обработка остаётся локальной, требование ТЗ §7 выполняется ([detection_design.md](../../analysis/detection_design.md)). TLS завершается на Cloudflare, поэтому `/api` не кэшируется, а кадры помечены `private`.
- В режиме `train` туннель может оставаться поднятым и отдавать 502: в окно жюри режим `train` запрещён.

Что проверяет решение:
- Ворота G0: curl из ТЗ с телефона через мобильную сеть на публичный URL получает валидный по схеме ответ; запрос без ключа — 401; загрузка через UI проходит.
- `just jury-sim URL KEY 5` с Windows-ПК через телефонную точку доступа.
- Репетиция: отключить сеть на 30 с — обработка продолжается, туннель переподключается.
- Условие релиза: curl из ТЗ на 3 видео с выключенным Wi-Fi проходит локально (сервис не зависит от сети).
