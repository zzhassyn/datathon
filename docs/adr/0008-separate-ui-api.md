# ADR-0008. Отдельный API для UI: без ключа, лимиты по IP, URL вместо base64, превью mp4

> Назначение: зафиксировать, через какие маршруты работает веб-интерфейс и как они защищены, не затрагивая API жюри.
> Владелец: S0 (документ); реализуют S1 (`api/routes/ui.py`, `api/ratelimit.py`, `api/preview.py`, `pipeline/ingest/preview.py`) и S2 (`web/`). Статус: черновик v1, 17.10.2026.

## Статус

Принято. Открытый вопрос grill-me: нужен ли код доступа в UI (умолчание — нет, только лимиты по IP).

## Контекст

- FAQ 27: авторизация в интерфейсе не нужна.
- Открытая загрузка на единственный Mac 16 ГБ — риск перегрузки. Защита не должна касаться ключа и очереди жюри.
- `<video>`, `<img>` и `EventSource` не умеют отправлять заголовки, значит `X-API-Key` для медиа не подходит. Ключ жюри нельзя класть в бандл.
- Ответ жюри заморожен ([ADR-0006](0006-frozen-jury-contract.md)). UI нужно больше: этапы, нормы с цитатами, сигналы, деградации.
- Браузеры: Chrome отказывается играть часть .mov; Safari требует HTTP Range; файлы с moov в конце тормозят начало воспроизведения.
- Кадры с камеры не должны кэшироваться на Cloudflare.

## Решение

1. **Маршруты `/api/ui`:**
   - `POST /api/ui/jobs` — multipart `file` (.mov или .mp4) → 200 `{"job_id"}`; ошибки 413, 415, 422, 507, 429 с `Retry-After`;
   - `GET /api/ui/jobs/{id}` → `UiJobView`;
   - `GET /api/ui/jobs/{id}/video.mp4` — faststart H.264, Range (206), ETag, `private, max-age=3600`; 404 до готовности;
   - `GET /api/ui/jobs/{id}/frames/{name}` — `name` по `^\d{1,2}_(event|zoom|context)\.jpg$`, путь проверяется `is_relative_to(job_dir/evidence)`, `private, max-age=31536000, immutable`;
   - `GET /api/ui/catalog` → `UiCatalog`, ETag = `config_hash`, 304 на `If-None-Match`;
   - `POST /api/ui/session` — только если задан `CG_UI_ACCESS_CODE` (cookie HttpOnly, SameSite=Strict); по умолчанию выключено.
2. **Тот же `ingest_upload`**, что у жюри ([ADR-0004](0004-auth-before-body-streaming-upload.md)), с principal `ui` и приоритетом 1 (жюри — 0).
3. **Лимиты UI:** по умолчанию 5 загрузок за 10 мин с IP, 2 активные задачи с IP, общий лимит очереди UI — 10; сверх — 429 с `Retry-After`. В окне жюри — профиль «окно жюри»: 30 загрузок за 10 мин с IP, 5 активных с IP, общая очередь UI — 20. Жюри может загружать через UI (FAQ 13), видео 5 и больше (FAQ 12), несколько человек могут быть за одним NAT. Профиль ставится в чек-листе заморозки [jury_mode.md](../jury_mode.md). Настраиваются через `CG_UI_RATE_*`. UI-задачи идут по тем же рубежам дедлайна от t0, что и задачи жюри ([ADR-0005](0005-deadline-tiers-provisional-degradation.md)). Ключ жюри никогда не лимитируется и не ограничивается очередью.
4. **IP клиента** — из `CF-Connecting-IP`, только если пир — `127.0.0.1`.
5. **Без base64.** `UiJobView` и `UiViolation` несут URL кадров, нормы с цитатами (`UiLegalRef`), сигналы, этапы, деградации.
6. **Превью:** после COMMIT API делает remux в `preview.mp4` в потоке (без перекодирования, ≤ 0,3 с, оценка). HEVC или повёрнутое видео ставит `needs_transcode`; perception worker перекодирует через `h264_videotoolbox`. До готовности `UiJobView.video` = null; клиент играет локальное превью через `URL.createObjectURL`.
7. **Каталог** отдаётся один раз и кэшируется по ETag. Он же питает страницу «Типы нарушений и нормы» (`?view=types`).

## Рассмотренные альтернативы

| Альтернатива | Почему отклонена |
|---|---|
| UI ходит прямо в `/api/v1` | Нужен ключ в браузере. base64 в каждом опросе. Замороженная схема не несёт этапов, норм с цитатами и сигналов |
| Авторизация UI по заголовку | `<video>`, `<img>` и `EventSource` не отправляют заголовки |
| Ключ жюри в бандле | Ключ утекает любому, кто открыл страницу |
| Открытая загрузка без лимитов | Один посетитель может забить очередь единственного Mac |

## Последствия

Плюсы:
- UI развивается без риска для замороженной схемы жюри.
- Мгновенное и надёжное воспроизведение во всех браузерах, включая Safari и iPhone.
- Кадры не кэшируются на Cloudflare (`private`).

Минусы и цена:
- Две поверхности API, обе нужно тестировать.
- Лимиты по IP могут мешать демонстрации нескольких загрузок с одного IP. Решается настройкой `CG_UI_RATE_*` или загрузкой через API с ключом team.
- На Linux нет VideoToolbox: способ перекодирования превью там нужно определить отдельно (проверить, см. [architecture.md, раздел 12.2](../architecture.md#122-перенос-в-контур-банка-linux--cuda)).

Что проверяет решение:
- `tests/api`: 429 и `Retry-After`; Range 206; регулярное выражение имени кадра и `is_relative_to`; 304 по ETag каталога.
- Playwright `mobile.spec.ts`: WebKit и iPhone на Mac.
