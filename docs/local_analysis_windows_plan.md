# Локальный анализ видео на Windows

Основание: задание пользователя от 18.10.2026. Реализация в `codex/local-video-analysis`,
отдельный managed worktree; исходный checkout и незавершённые изменения не меняются.

## Объём

1. Сохранить jury/UI схемы, SQLite очередь, lease/CAS и существующие ошибки.
2. Подключить отдельный локальный ML-процесс с проверенными trained PT main/hands/door,
   CUDA при доступности, PTS, настоящим прогрессом и проверкой полного прохода.
3. Реализовать одно правило из исходного ТЗ с обязательной калибровкой камеры,
   временными границами и 1–3 локальными кадрами-доказательствами. Отсутствующая
   калибровка/модель/неполная обработка — ошибка, без чистого вердикта.
4. Исправить readiness, происхождение старых stub результатов и отображение стадий,
   событий, моделей и ошибок. Не менять замороженные схемы.
5. Тесты сначала для новых правил/ошибок; затем backend/web checks и реальный
   локальный сквозной прогон на разрешённом исходном видео с числовым отчётом времени.

## Ограничения

Без обучения, Brev, изменения датасетов/очередей, облачного инференса, публикации.
API не импортирует ML. Процессы spawn. Банковские медиа доступны только локальным
скриптам/плееру человека; агент проверяет код/числовые отчёты. Исходные модели
не подменяют trained веса. Дверь только по известному ROI: RGB whole-crop resize224,
float32/255; closed не означает locked. Все не реализованные правила явно указать.

## Проверки особых случаев

- Отсутствующий/неверный вес или неизвестный класс → понятный failed.
- Неизвестная камера/ROI → отказ от недостоверного чистого результата.
- Нет PTS, обрыв декодирования, deadline, NaN → failed, без no_violation.
- Исчезновение/повторное появление предмета, одиночный false positive → границы события.
- Старое stub задание после включения full остаётся помечено синтетическим.

Реализован технический срез PERSONAL_ITEMS по п.5 списка нарушений. Поверхность

публикация событий/доказательств проверена числовой синтетической фикстурой.

ruff/basedpyright/import-linter/Biome/TypeScript/schema drift и production build
прошли. Реальный X-2: 510 decoded / 35 sampled, CUDA, 15.58с inference,
16.25с backend, 18.059с от отправки через UI до terminal. Независимое ревью:
Critical/Important замечаний нет. Качество на неизвестных видео, другие нарушения,
VLM и Mac не проверены. Readiness в конце прогона: 503 из-за 2.16ГБ свободной RAM
при минимуме 3ГБ; остальные readiness checks прошли. Порог памяти сохранён.
