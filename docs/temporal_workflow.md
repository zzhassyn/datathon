# Пилот анализа сцены во времени

Рабочая ветка добавляет историю сцены поверх существующих API, очереди и
локального PT-worker. Переписывания инфраструктуры и изменения схем жюри нет.
Это кандидат для проверки, не принятый выпуск всей системы.

## Подключение

Используйте существующий запуск из `docs/local_analysis_windows.md`, указав
`CG_LOCAL_ANALYSIS_CONFIG` на копию `configs/local_analysis.temporal.example.json`.
Заполните абсолютные пути к проверенным весам, исходному видео и файлу
калибровки. Для Mac PT-путь использует CPU; Core ML этим изменением не подключён.

На локальной странице `/local-calibration` человек последовательно выделяет:
поверхность стола, сторону кассира (место человека), сторону клиента, видимый
выход и сейф с местом работы около него. Невидимые зоны оставляет пустыми.
Дополнительное подтверждение зон сохраняется только действием человека.
Принадлежность личных вещей не нужна правилам ухода/сейфа.

При `temporal_rules.enabled=true` worker добавляет BoT-SORT без распознавания
лиц/ReID. Обработчик сохраняет `scene.json`, `rule_candidates.json` и
`technical_scope.json`. Выходной таймкод и доказательства выбираются по PTS.
`VALUABLES_LEFT` и `SAFE_OPEN` используют существующий каталог описаний и норм.
Косвенная норма сейфа сохраняет условную формулировку каталога.

## Ограничения и приёмка

- Конец клипа и потеря трека вне видимого выхода не подтверждают уход.
- Деньги должны непрерывно наблюдаться; пропуск или смена ID разрывают интервал.
- Неизвестная роль не становится кассиром или клиентом автоматически.
- Сумка без наличных требует отдельного внутреннего основания; вердикт отключён.
- `PREV_CASH_ON_DESK` требует положительно подтверждённой передачи денег;
  текущий scene builder её не извлекает. Этот код не включён по умолчанию.
- Остальные сценарии PDF не объявляются проверенными.
- Пустой список кандидатов сохраняет блокировку чистого вердикта. Ни точность
  детекторов, ни полнота видимости действий ещё не дают основания для `no_violation`.
- Qwen в этот путь пока не включён. Адаптер NVIDIA не прошёл приёмку качества.

Проверки на синтетических числовых сценах подтверждают программную логику,
но не заменяют измерение качества на банковских роликах. Перед выпуском нужны
человеческая проверка зон и примеров, точность типов/таймкодов на отложенных
видео, отсутствие новых ложных срабатываний на чистых сценах и измерение
полного времени через API (лимит 300 секунд). `just eval-replay` пока заглушка:
использовать её вывод как успешную проверку нельзя.
