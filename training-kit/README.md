# Полный комплект данных для обучения Forte

[Скачать один ZIP (1.92 ГБ)](https://github.com/zzhassyn/datathon/releases/download/training-kit-20261017-185808/Forte_Training_Kit_20261017_185808.zip) · [Релиз](https://github.com/zzhassyn/datathon/releases/tag/training-kit-20261017-185808)

Закрытый репозиторий: для скачивания войдите в GitHub под аккаунтом с доступом.
В архиве все актуальные материалы: 40 уникальных банковских видео, 752 кадра,
605 кропов, 5 881 внешнее изображение, 37 внешних клипов, исходные метки,
лицензии, редактор, экспорт YOLO/COCO, классификаторы, задания Qwen/событий/трекинга
и команды локального обучения. Веса моделей не включены.

## Первые команды

Полностью распакуйте ZIP, перейдите в папку `Forte_Training_Kit_20261017_185808`:

```bash
python3 restore_media.py
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r tools/training/requirements-data.txt
python tools/datasets/validate_training.py
python tools/training/run.py --list
```

Нужен Python 3.11+. В ZIP одинаковые медиафайлы хранятся один раз.
Первая команда восстанавливает 3 159 повторяющихся путей без скачивания,
без изменения изображений и разметки. Нужные пути всех файлов возвращаются.
Сначала прочитайте `НАЧАТЬ_ОБУЧЕНИЕ.txt`; подробности — `README_RU.txt` и `00_START.html`.

Наборы пересекаются по фото, поэтому числа нельзя складывать как независимые примеры.
`source_labels_ready` означает, что разметка подготовлена для отдельной задачи,
а не что качество модели уже измерено.

**Основной банковский детектор на 14 классов пока не готов:** полная разметка
752 кадров не подтверждена. Также нет подтверждённых поз пальцев, плотных треков,
интервалов событий и эталонных объяснений Qwen. Неразмеченные кадры не стали фоном.
Небольшие наборы печатей, счётчиков и детектора пока без проверочной выборки;
их запуск заблокирован. Для предварительных меток нужен `--allow-provisional`.

## Пример запуска

Из распакованного комплекта:

```bash
python -m pip install -r tools/training/requirements-yolo.txt
python tools/training/run.py --profile aux_common_objects_s
python tools/training/run.py --profile aux_common_objects_s --run --weights /path/to/yolo26s.pt
```

Первая команда launcher делает dry run. Для реального обучения нужны локальные веса
и `--run`. На Mac используется MPS; для NVIDIA добавьте `--device cuda`.
Проверки данных выполнены, ML-окружение и само обучение здесь не запускались.

## Схема и происхождение

Для текущих YOLO-меток используйте `datasets/forte_v1/schema.json` внутри ZIP
или [annotation_schema.json](annotation_schema.json). Аналитические предложения
из `analysis/detection_design.md` используют другую группировку классов;
не подставляйте их номера без явной миграции. Копия анализа включена в
`analysis_reference/`; typed CSV — интерпретации команды, не исходные типы организатора.

Связанные записи и подтверждённые похожие фото объединены до обучения.
Новый кабинет, ракурс и ложные тревоги по нарушениям ещё не проверены.
Полная информация о каждом источнике и точных лицензиях включена в ZIP;
банковские исходники используйте только в разрешённых рамках команды.
