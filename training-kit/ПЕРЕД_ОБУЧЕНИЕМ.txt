1. Распакуйте ВЕСЬ ZIP в отдельную папку. Не запускайте обучение внутри ZIP.
2. Из этой папки:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r tools/training/requirements-data.txt
python tools/datasets/validate_training.py
python tools/training/run.py --list

Эти команды проверяют данные, но не обучают модель.

ДЛЯ ЭКСПЕРИМЕНТА С ДЕТЕКТОРОМ
python -m pip install -r tools/training/requirements-yolo.txt
python tools/training/run.py --profile aux_common_objects_s
python tools/training/run.py --profile aux_common_objects_s --run --weights /путь/к/yolo26s.pt

Веса нужны локальные. Автозагрузка весов в launcher выключена.
Mac: профиль mps, batch 2. На Linux с NVIDIA добавьте --device cuda.
Большую модель на Mac с 16 ГБ сначала проверяйте с batch 1.
Работу ML-библиотек и расход памяти здесь не проверяли.

Вспомогательные наборы НЕ являются полной разметкой банковских 14 классов.
CommonObjects5 и COCO80 используют одни фотографии с разными схемами: их
нельзя считать независимыми выборками или просто смешивать в один датасет.
Для каждого эксперимента используйте его data.yaml и его карточку.
Аналогично: cash/hand/key/drawer обучаются отдельными головами.

Для предварительных состояний сейфа/экрана и cash_seed нужен
--allow-provisional. Это маленькие наборы для первых экспериментов,
а не доказательство качества на новых ракурсах. Профили без проверенных
train/val запускаются с блокировкой, чтобы не обучаться на пустых метках.

здесь нет SFT-набора с проверенными объяснениями и нет её весов.

Схема классов для обучения: datasets/forte_v1/schema.json, object_classes.
Файл analysis_reference/detection_design.md содержит более раннее предложение
с другими именами/группировкой классов. Не используйте его номера классов
в текущих YOLO-метках. Нужна явная миграция схемы, если команда решит её сменить.
analysis_reference/labels_typed.csv — интерпретации из репозитория команды,
а не выданные организатором типы событий или проверенные интервалы.
Светящийся экран сам по себе не доказывает отсутствие блокировки.

Технические проверки: SHA изображений, геометрия рамок, исходные координаты,
группы и переносимость путей. Последняя проверка похожих фотографий не нашла
необработанных межвыборочных пар среди экспортируемых компонентов при
заданном пороге pHash; это не гарантия отсутствия всех похожих съёмок.
