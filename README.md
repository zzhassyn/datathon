# CashGuard

**Видео кассы → признаки нарушения → таймкод → кадры-доказательства**

Локальный AI-сервис для ForteBank Datathon 26.<br>
Обработка без облачных AI-вызовов и распознавания лиц.

[Запуск](#быстрый-запуск) · [Охват](#что-проверяет-сервис) · [API](#проверка-через-api) · [Проверки](#проверки-и-качество) · [Документация](docs/README.md)

</div>

---

CashGuard принимает `.mov` и `.mp4`, находит видимые признаки возможных нарушений и помогает человеку проверить событие. Результат: `violation` / `no_violation`, тип, таймкод PTS, 1–3 кадра-доказательства, описание и нормативное основание из каталога.

> [!IMPORTANT]
> Профиль ниже проверяет **3 типа из 26** в каталоге. Качество последних изменений на реальных видео ещё не измерено. `no_violation` означает отсутствие срабатываний выбранных правил, а не проверку всех возможных нарушений.

## Быстрый запуск

Нужны **Python 3.12 · uv · Node.js 24.22.0 · pnpm 10.34.7**.

```bash
git clone https://github.com/zzhassyn/datathon.git
cd datathon
uv run just setup
uv run just build-web
uv run just dev 8137
```

Откройте [localhost:8137](http://127.0.0.1:8137). Это режим **stub без моделей**: он проверяет интерфейс, API и очередь на синтетических видео. Для распознавания нужны локальные веса и [полный запуск](#полный-анализ-с-локальными-моделями).

В интерфейсе можно загрузить видео до 100 МБ, следить за обработкой и перейти к событию по таймкоду. Карточка показывает описание, норму и кадры. [Подробнее об интерфейсе →](docs/ui.md)

## Что проверяет сервис

Набор правил задаётся в `temporal_rules.codes`. В профиле из этого README:

| Правило | Что ищет | Ограничение |
|---|---|---|
| `VALUABLES_LEFT` | Наличные без присмотра после подтверждённого выхода кассира | Нужны наличные и отсутствие людей на всём минимальном интервале |
| `THIRD_PERSON_DURING_SERVICE` | Двух и более посетителей у стола в течение 2 с | Порог — оценка; кассир, дубли и фон исключаются |
| `SAFE_OPEN` | Оставленный открытым сейф | В историческом прогоне детектор почти не выдавал `safe_open`; качество ограничено моделью |

**Адаптивный фильтр посетителей включён по умолчанию.** Он оценивает размер по устойчивым наблюдениям людей в текущий момент; при недостатке данных использует прежний порог площади. Для сравнения доступен `person_size_mode: "fixed"`. [Алгоритм и регрессии →](docs/pipeline.md#устойчивость-числовых-правил)

Автозоны — оценка по детекциям. Если стол не найден, `auto_zones` возвращает `no_violation` с внутренней причиной `scene_not_recognized`; если стол найден, но кассир неоднозначен, результат — `failed`. При ручной калибровке отсутствие кандидатов пока блокирует чистый вердикт. При сэмплировании 2 кадра/с короткое событие может быть пропущено.

**Текущий путь обработки:** PyAV (PTS) → YOLO26s / PyTorch → BoT-SORT без ReID → сцена → правила → кадры и описание. API работает отдельно от ML; задачи хранятся в SQLite WAL. Core ML и Qwen не подключены к этому профилю.

[Каталог и основания правил](docs/violation_catalog.md) · [Нормативные источники](docs/legal_sources.md) · [Ограничения](docs/limitations.md)

## Полный анализ с локальными моделями

Нужны отдельное ML-окружение, локальные веса и конфигурация с путями и SHA-256. Пример использует PyTorch на CPU. Исторический хост — MacBook Pro M2 Pro, 16 ГБ; новая версия на Mac ещё не проверена.

<details>
<summary><strong>Настройка и запуск — Bash / zsh</strong></summary>

1. Выполните `setup` и `build-web` из быстрого запуска. Подготовьте отдельное Python 3.12 окружение с extra `ml` по [pyproject.toml](pyproject.toml) и `uv.lock`; его Python укажите в `CG_LOCAL_MODEL_PYTHON`.
2. Создайте ключи: `uv run just gen-key`. Они сохраняются в `~/.config/cashguard/.env` и не печатаются.
3. Скопируйте [пример конфигурации](configs/local_analysis.temporal.example.json), задайте свои абсолютные пути и SHA-256 весов. Замените только блок `temporal_rules`, сохранив остальные поля:

```json
{
  "temporal_rules": {
    "enabled": true,
    "auto_zones": true,
    "codes": ["VALUABLES_LEFT", "SAFE_OPEN", "THIRD_PERSON_DURING_SERVICE"],
    "min_duration_sec": 2,
    "person_size_mode": "adaptive"
  }
}
```

4. Запустите сервис, заменив пути на свои:

```bash
CG_PIPELINE_MODE=full CG_VISION_BACKEND=torch CG_VLM_ENABLED=false \
CG_PIPELINE_VERSION=numeric-rules-v4 \
CG_LOCAL_MODEL_PYTHON="/absolute/path/.venv-model/bin/python" \
CG_LOCAL_ANALYSIS_CONFIG="/absolute/path/local_analysis.json" \
CG_WEB_DIST="$PWD/web/dist" CG_DATA_DIR="$PWD/var" CG_UI_RATE_PROFILE=jury \
HF_HUB_OFFLINE=1 YOLO_OFFLINE=1 PYTHONPATH=src \
uv run python -m cashguard.cli up --profile prod --port 8137
```

5. Дождитесь `200` от `/ready`, затем проверьте загрузку через API. Для временного публичного адреса:

```bash
cloudflared tunnel --url http://127.0.0.1:8137 --no-autoupdate
```

Адрес quick tunnel меняется после перезапуска. При обновлении правил меняйте `CG_PIPELINE_VERSION` для API и воркеров и перезапускайте сервис: версия участвует в идентификации задач. Изменения JSON учитываются в отпечатке конфигурации.

[Ручная калибровка](docs/temporal_workflow.md) · [Локальный запуск на Windows](docs/local_analysis_windows.md)

</details>

## Адреса и доступ

| Что | Где |
|---|---|
| Веб-интерфейс | Локально — `http://127.0.0.1:8137`; актуальный публичный URL передаётся отдельно |
| API жюри | `<URL>/api/v1`, ключ в заголовке `X-API-Key` |
| Диагностика | `/health` — процесс жив; `/ready` — готовность выбранного режима |
| Типы нарушений | `<URL>/?view=types` |

Ключ выдаётся отдельно; интерфейс открыт без входа, загрузки ограничены по IP. Swagger в боевом профиле выключен. В режиме stub готовность не означает загрузку моделей.

## Проверка через API

```bash
# Загрузить видео; ответ содержит job_id
curl -X POST "<URL>/api/v1/analyze" \
  -H "X-API-Key: <API_KEY>" -F "file=@video_017.mov"

# Опрашивать до status=done или failed, например раз в 3 с
curl "<URL>/api/v1/jobs/<job_id>" \
  -H "X-API-Key: <API_KEY>" -o result.json
```

Ответ сохраняется в файл: он содержит JPEG в base64. При `done` возвращаются вердикт и до пяти нарушений; при `failed` вердикт равен `null`. Первый кадр-доказательство совпадает с таймкодом события.

[Контракт и ошибки API](docs/api.md) · [Замороженная JSON Schema](src/cashguard/contracts/schemas/jury_job.schema.json) · [Сквозная smoke-проверка](scripts/smoke_jury.sh)

## Проверки и качество

```bash
uv run just check
```

Единая проверка: Ruff, basedpyright, import-linter, pytest, Biome, TypeScript, Vitest и дрейф схем.

Последний полный прогон на Windows: **933 Python-теста и 36 web-тестов прошли**. Шесть Python-тестов пропущены из-за отсутствия Torch и ограничений Windows (symlink / SIGSTOP). Mac-инференс и реальные видео в этот прогон не входили.

| Исторический прогон 18.10.2026 | Результат |
|---|---|
| Найденные нарушения | 3 из 20; пропущено 17 |
| Ложные срабатывания | 0 на 20 чистых роликах |
| Время через публичный API | Медиана ≈ 18 с, максимум ≈ 105 с — оценка по округлённому отчёту |

Это результаты **прежней версии** на роликах, из которых брали кадры для обучения. Разбиение отчёта 20/20 отличается от текущего канонического 21/19. Для оценки нынешних правил нужны числовые replay-трассы; синтетические регрессии не заменяют precision/recall.
