# CLAUDE.md — заметки только для Claude Code

> **Назначение:** дополнения к [AGENTS.md](AGENTS.md), которые касаются только Claude Code. Общие правила здесь не дублируются.
> **Владелец:** S0 (интегратор) · **Статус:** черновик v1, 17.10.2026

- **Источник правил — `AGENTS.md`.** Если заметка ниже ему противоречит, прав `AGENTS.md`. Симлинков нет: файл подключается строкой `@AGENTS.md`.
- **Windows.** Инструмент Bash — это Git Bash, а рецепты `just` на Windows идут через PowerShell. Команды проекта запускайте как `uv run just <recipe>`, а не через голые `python` или `pnpm`.
- **Worktree.** Основной способ — `../cg-wt/<slug>` из `AGENTS.md`. Собственные worktree Claude Code лежат в `.claude/worktrees/` (в `.gitignore`). У каждого worktree свои `var/` и порт.
- **Запреты на чтение.** В P0 S0 добавит `.claude/settings.json` с `permissions.deny` для `Read(./data/**)`, `Read(./var/**)`, `Read(./models/**)`, `Read(./runs/**/*.jpg)`, `Read(**/*.mov)`, `Read(**/*.mp4)`. Числовые отчёты в `runs/` (`results.csv`, `timing.json`, `eval_*.md/json`) читать можно. На Mac человек добавляет пользовательский `~/.claude/settings.json` с абсолютными путями к `~/cashguard/{data,var,models}` и `~/cashguard/runs/**/*.jpg`: относительные правила не закрывают их из worktree `~/cg-wt/<slug>`. Не обходите их через Bash (`cat`, `ffmpeg`, `python -c`) и не открывайте изображения из этих папок. Менять `.claude/settings.json` может только человек.
- **Коннекторы и веб-инструменты.** Не передавайте в MCP-коннекторы, веб-поиск, артефакты и память сессий кадры, видео, их описания и содержимое `var/`. Это та же «облачная обработка», что запрещена ТЗ §7.
- **Субагенты.** Субагент получает те же границы владения, что и сессия. Если задача задевает `contracts/`, `pyproject.toml` или чужую папку, остановитесь и опишите нужное изменение для S0 или владельца.
- **Git.** Коммит и push — только по просьбе человека. Мержит S0, fast-forward. Не используйте `--no-verify`: хуки `prek` — часть шлюза.
- **Mac-задачи** (Core ML, MLX, launchd, туннель) выполняет сессия, запущенная на самом Mac (S3 или S6). На Windows такие тесты помечаются `@pytest.mark.mac` и пропускаются.
- **Длинные команды** (`just dev`, `pnpm dev`, обучение) запускайте в фоне и не ждите их через `sleep`.
