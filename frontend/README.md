# Forte Vision — frontend

Минималистичный интерфейс в стиле Frigate с акцентами Forte: камеры, загрузка видео, таймкод, четырёхсекундный контекст, кадры-доказательства и нормативный источник.

## Запуск

Node.js 22+:

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5173/

```sh
npm run build
npm test
```

## Текущее поведение

- Три демопотока используют одну запись Х-34 с разным начальным временем.
- Разметка примера подготовлена вручную. Модель и backend не подключены.
- Загруженный файл открывается через локальный object URL. Он не отправляется на сервер и не получает демонстрационные события.
- Карточка примера: 13 секунда, контекст 11–15 секунд, JPEG-кадры на 11, 13, 15 секундах.
- Источник: постановление НБРК № 231 от 29.11.2019, пункт 20. Наблюдение требует проверки человеком.
- Выбор камеры, пауза потоков, видеоплеер, переход по таймкоду, увеличение кадров и раскрытие источника работают в браузере.

## Основные файлы

- `src/App.tsx` — активный интерфейс.
- `src/styles.css` — тёмная тема и адаптивная компоновка.
- `src/workspace.ts` — проверка файлов и форматирование таймкодов.
- `public/demo/` — локальные демоматериалы.

В `src/api/`, `src/pages/`, `src/components/` сохранены модули предыдущего прототипа. Они не подключены к текущему интерфейсу. При интеграции модели следует заменить ручную карточку данными API: POST `/api/v1/analyze`, GET `/api/v1/jobs/{job_id}`. Не применять прежний mock-анализ к загруженным пользователем файлам.

Демо содержит материалы кейса: использовать в рамках хакатона. Публикация и backend не настроены.

## Демо на другом компьютере

Исходные видео кейса и извлечённые кадры не входят в Git. Для того же демо разместите локально в `public/demo/` файлы `case-34.mp4`, `context-34.mp4`, `frame-5.jpg`, `frame-11.jpg`, `frame-13.jpg`, `frame-15.jpg` из подготовленного frontend. Они исключены через `.gitignore`. Без них сборка работает, но пример камеры и доказательства недоступны; выбор собственного видео остаётся доступен.

Исходник Х-34 сохранён в ранее переданном приватном training-kit release: https://github.com/zzhassyn/datathon/releases/tag/training-kit-20261017-185808 .
