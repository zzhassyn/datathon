# Проверка MVP — 17 октября 2026

- `pnpm build`: TypeScript и production-сборка прошли. Основной JS около 296 КБ (gzip около 91 КБ); demo WebM около 368 КБ.
- `pnpm test`: 43 проверки прошли — API-контракт, mock/HTTP-ошибки и отмена, локальные адреса, хранение без медиабайтов/ключа, дробные таймкоды.
- Локальный сервер и demo WebM возвращают HTTP 200.
- В браузере пройдены: новый демоанализ с событиями; отдельный clean-сценарий; отдельный failed-сценарий; переход через маркер к 15.8 секунды; Original / AI Analysis; подтверждение события; сохранение истории после перезагрузки; поиск без совпадений.
- Проверен выбор настоящего локального файла через file chooser. WebM воспроизводится (24 секунды, readyState 4), JPEG-кадр извлекается локально. После перезагрузки видео отсутствует до повторного выбора; повторный выбор восстанавливает плеер и кадр.
- Из материалов кейса выбран X-1.mov: браузер прочитал размер около 5 МБ, длительность 25.933 секунды, кодек воспроизводится без ошибки. На API этот файл не отправлялся.
- Внешние AI-сервисы не использовались. Встроенные media и bbox синтетические; model confidence не придуман.
- Визуально проверена компоновка в панели браузера шириной 730 px: навигация сворачивается в меню, карточки событий располагаются горизонтально, таблица допускает прокрутку. Остальные размеры предусмотрены CSS, но отдельный набор устройств не тестировался.
- Независимый review привёл к исправлениям: точность дробных таймкодов, выбор события через таймлайн, временные интервалы bbox, ожидание API-ключа после reload, проверка размера/длительности повторно выбранного видео.

Настоящего backend в репозитории нет. Live HTTP-интеграция с AI-сервисом, точность моделей и 300-секундный end-to-end benchmark не проверены. HTTP-клиент проверен автоматическими тестами с контролируемыми ответами. Серверная история и отмена задач не реализованы.
