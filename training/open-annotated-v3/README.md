# Forte Open Annotated v3 — датасеты YOLO и Qwen

[Полный архив в закрытом GitHub Release](https://github.com/zzhassyn/datathon/releases/tag/open-annotated-v3-20261018) — **444 379 197 байт, 2 767 файлов**. Доступен участникам приватного репозитория. В Git находятся описание, отчёты и SHA-256; видео, изображения, разметка, просмотрщик и скрипты находятся во вложенном ZIP.

Это экспериментальный набор для подготовки обучения. Статус разметки — `ai_visual_reviewed`, `human_verified=false`. Обучение и инференс не запускались. Качество на новой камере не измерено.

667 кадров последовательной выборки и 40 последних кадров просмотрены; выделено 258 фаз. Это выборка примерно раз в 2 секунды, а не сплошная покадровая разметка. Короткие действия между выбранными кадрами могут быть пропущены. Новые вырезки двери заменяют прежнюю выборку, а не добавляются к ней. 68 внешних изображений переиспользованы с сохранением происхождения и лицензий.

Разделение общее для задач: 29 train-видео, 5 val, 6 test, 17 групп исходных дублей. Тестовые примеры не передаются обучению и подбору параметров. Разделение по дублям не доказывает переносимость на другую камеру.

## Роли и запуск

| Роль | Модель и статус |
|---|---|
| 14 классов предметов и людей | YOLO26 detect; сервисная цель `l/864`, локальный эксперимент `s/640`; общая разметка для размеров одной задачи |
| Дверь closed/open | YOLO26s-cls, отдельный датасет и обучение; вся фиксированная вырезка приводится к 224×224 |
| Проверка визуальных вопросов | Qwen3.5-4B, подготовлен экспериментальный LoRA runtime на 4-bit базе |
| Положение тела | Готовая YOLO26l-pose; разметки суставов в v3 нет, 17 точек тела не заменяют суставы кисти |
| Экран и замок | Обучение отключено: нужны достоверные метки |
| Треки людей | BoT-SORT без ReID, настройка без отдельного обучения |

В архиве `train.py` проверяет данные и печатает план по умолчанию. `--check-loaders` последовательно проверяет загрузчики трёх задач. `--run --tasks detector,door,qwen` предназначен для будущих отдельных обучений с отдельными результатами. Команда объединяет запуск, а не веса моделей.

**ZIP не содержит Python-окружений и весов.** По умолчанию используются соседние локальные комплекты `Forte_M2Pro_Reviewed_v2` и `Forte_Temporal_Finetune_v1`. На другой машине необходимо указать `--yolo-python`, `--qwen-python`, `--detector-weights`, `--door-weights`, `--qwen-model`. Версии зафиксированы в `runtime/*.lock` внутри ZIP и отличаются от окружения сервиса. Подробная инструкция — [README_RU.txt](README_RU.txt).

Скрипты v3 являются отдельным экспериментом и не заменяют сервисные `training/scripts/00–12` и `run_stage_*.sh`. На машине сервиса сохраняется требование не совмещать `serve` и `train`; запуск через сервисные `just train-a` / `just train-c` не подключён к v3 автоматически. Совместимость, запуск обучения и экспорт нужно проверить до интеграции.

## Ограничения интеграции

- Для `outerwear` (class_id 13) нет положительных train/val-примеров; выход нельзя считать обученным. Редкие объекты и независимые сцены требуют пополнения.
- Qwen target: `{"answers":[{"qid":"q1","a":"yes|no|unclear"}],"note":"..."}`. Обязательное поле `c` прежнего сервисного контракта не размечено; требуется явный адаптер схемы и отдельная калибровка. Перенос LoRA с 4-bit базы на сервисную 8-bit модель не проверен.
- Все 40 примеров `unclear` относятся к состоянию замка; нужны другие виды неопределённости и одинаковые вопросы с разными ответами.
- Закрытая дверь или сейф не доказывают, что они заперты. Фон экрана не доказывает блокировку ОС.
- Наблюдения модели должны поступать в отдельный код временных правил. Готового детектора нарушений и подтверждённого качества всей цепочки этот архив не содержит.

Полный перечень пробелов: [DATA_GAPS_RU.txt](DATA_GAPS_RU.txt). Роли и их машинные статусы: [training_tasks.json](training_tasks.json).

## Получение и проверка

Из корня репозитория (архив сохранится в игнорируемом `data/`):

```bash
gh release download open-annotated-v3-20261018 --repo zzhassyn/datathon --pattern 'Forte_Open_Annotated_v3.zip*' --dir ./data/open-annotated-v3-download
cd ./data/open-annotated-v3-download
shasum -a 256 -c Forte_Open_Annotated_v3.zip.sha256
python3 -m zipfile -t Forte_Open_Annotated_v3.zip
unzip -q Forte_Open_Annotated_v3.zip
```

SHA-256 фиксирует точное содержимое ZIP; CRC проверяет читаемость его файлов. Метаданные: [release_info.json](release_info.json), контрольная сумма: [SHA256SUMS](SHA256SUMS).

Проверены SHA-256 и CRC архива, уникальность и безопасность путей, количество и наличие обязательных файлов, совпадение отчётов с опубликованным снимком. В подготовке v3 прошли проверка данных, реальные загрузчики Ultralytics и CPU-токенизация всех 120 Qwen-примеров (максимум 862 токена, без обрезки, loss только на ответе). [verification.json](verification.json) фиксирует именно эти проверки: forward/backward, качество распознавания, экспорт и полный сервисный `just check` этим не подтверждаются.
