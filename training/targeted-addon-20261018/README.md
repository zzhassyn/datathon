## Совместимость с v3

- У v3 `counting_machine` имеет ID 7; в нашей отдельной задаче `cash_counter` имеет ID 0. Нужны преобразование ID и полная разметка всех целевых объектов перед включением в 14-классовый детектор.
- `key` и `stamp` отсутствуют в текущей 14-классовой схеме v3. Нельзя добавлять их без согласования схемы или выделения отдельной модели.
- Неразмеченные фотографии не являются отрицательными примерами. Рамки одного класса не означают полноту остальных классов.
- Связанные виды сгруппированы, включая связь новых ключей с ранее существовавшим `CommonsDomain__20493828`. При объединении нужно сверить группы с основным набором; тестовые примеры не использовать для обучения.

Разметка выполнена ассистентом и требует проверки человеком: `human_verified=false`. Обучение и оценка качества не проводились. Проверки целостности, геометрии экспорта и групп — [verification.json](verification.json).
