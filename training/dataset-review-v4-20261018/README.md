# Forte — пакет проверки дополнений v4

[Скачать ZIP из приватного GitHub Release](https://github.com/zzhassyn/datathon/releases/tag/dataset-review-v4-20261018) — **100 643 903 байта, 580 файлов**. Доступен участникам репозитория.

Это пакет кандидатов для проверки перед следующим обучением. Он не заменяет [Open Annotated v3](../open-annotated-v3/README.md), не содержит весь базовый датасет и не меняет уже запущенное обучение. Статус: **`human_verified=false`, `ready_for_training=false`**.

| Материалы | Результат |
|---|---|
| 59 фотографий CommonsDomain | 27 новых предварительных разметок; вместе с предыдущими — 40 изображений с рамками отдельных классов |
| Сложные фотографии | 19 отложены с причинами; не включены в YOLO-экспорт как пустой фон |
| Исходные Qwen QA | Структурная проверка 120, повторный визуальный просмотр 24 по выбранным кадрам |
| Новые Qwen QA | 18 кандидатов: 6 yes / 6 no / 6 unclear; 6 пар с одинаковыми вопросами и противоположными ответами |
| Внешние видео | 7 ранее скачанных роликов MEVA с 7 камер, выборочные кадры с PTS и заметки |

Новые QA происходят из 6 существовавших **train**-видео. Новых банковских сцен и новых скачанных файлов нет. Использование MEVA в предыдущем обучении неизвестно: этот набор не является независимым тестом банковских нарушений.

## Работа с пакетом

1. Распакуйте ZIP в отдельную папку. Существующий набор v3 оставьте без изменений.
2. Откройте `index.html` или запустите из распакованной папки `python3 -m http.server 8766 --bind 127.0.0.1`, затем перейдите на `http://127.0.0.1:8766/`.
3. Проверьте изображения, границы, вопросы, ответы и объяснения. Укажите имя проверяющего. Решения сохраняются в браузере; кнопка «Скачать решения» экспортирует отдельный JSON. Исходные аннотации и ZIP автоматически не изменяются.
4. После человеческой приёмки и согласования классов соберите новую версию обучения с фиксированными группами train/val/test. Запишите версию и SHA-256 в параметры запуска.

`objects/` содержит фотографии и предварительные рамки; `proposals/yolo/` — отдельные одноклассовые экспорты. `qwen/` содержит очередь проверки v3, аудит и 18 новых кандидатов; `external/` — ролики MEVA и кадры; `licenses/` — источники и лицензии. Подробности — [README_RU.txt](README_RU.txt).

## Ограничения

- Рамки имеют охват только своего целевого класса. В v3 `counting_machine` имеет ID 7; в отдельных наборах `cash_counter`, `key`, `stamp` имеют локальный ID 0. `key` и `stamp` отсутствуют в схеме v3. Автоматическое объединение не выполняется.
- Перед включением в общий детектор нужно разметить все видимые классы его схемы. Пустые поля полной разметки не означают отсутствие объектов.
- У счётчиков нет validation, у печатей один val-пример. Достаточность независимой оценки не подтверждена.
- Во всех 40 исходных `unclear` одна тема — замок. Аудит предлагает согласовать формулировку прямого вопроса о состоянии; исходные ответы и вопросы не изменены. Val/test сохранены отдельно от новых train-кандидатов.
- Закрытая дверь не подтверждает запирание; светящийся экран не подтверждает разблокировку ОС. Выборочные кадры не задают точные границы действий между ними.
- Обязательное поле `c` сервисного контракта Qwen не размечено; адаптация и калибровка выполняются отдельно. Этот пакет не содержит обученных весов или готового детектора нарушений.
- Кадры кейса остаются в приватном доступе команды. Лицензии публичных фотографий и MEVA приложены отдельно.

## Проверка архива

```bash
gh release download dataset-review-v4-20261018 --repo zzhassyn/datathon --pattern 'Forte_Review_Increment_v4_20261018.zip*' --dir ./data/review-v4-download
python3 training/dataset-review-v4-20261018/verify_archive.py ./data/review-v4-download/Forte_Review_Increment_v4_20261018.zip
```

SHA-256: `ba2d5ab3a3c69ac0ddaa39bf159c3eb7438cfe97b84a279a20b8e706cfbf12c4`.

Проверены контрольные суммы, CRC, пути внутри ZIP, пары изображений и меток, геометрия рамок и разделение групп. После распаковки `python3 verify.py .` проверяет внутреннюю структуру. В браузере проверены отображение рамок, загрузка кадров и метаданных видео, запрет сохранения без имени; решения от имени человека не создавались. Проверки не измеряют точность разметки или модели.

В Git находятся только описание, метаданные и проверка архива. ZIP опубликован отдельным prerelease, текущий обучающий выпуск v3 сохранён.
