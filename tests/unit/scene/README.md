# `tests/unit/scene/` — тесты `scene`

> **Назначение:** Модульные тесты пакета `src/cashguard/pipeline/scene`: зоны, роли, сеансы, интервалы, события.
> **Владелец:** S4 · **Статус:** синтетические тесты числовой сцены и автокалибровки.

`test_auto_zones.py` проверяет выбор кассира по столу, долгий фоновый трек,
дубли одного PTS, независимость от порядка рамок, неоднозначность и уход
кассира. `test_temporal.py` проверяет наблюдаемые интервалы: возвращение
человека и исчезновение денег до конца интервала не подтверждают оставленные
ценности. Все входы синтетические; видео и кадры датасета не используются.
