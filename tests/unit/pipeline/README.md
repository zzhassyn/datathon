# Тесты исполнения K4

Владелец — S0 (runner), S1 (связь progress/lease). Все входы синтетические:
числовые наблюдения и созданные в тесте одноцветные JPEG. Модели не запускаются.

`test_runner.py` проверяет последовательность стадий, идентичность/план/версии
трассы, покрытие sampled-индекса, исходные PTS, сроки, ошибки стадий, неверные
решения, evidence, согласованность jury/UI и сохранение артефактов. Отдельный тест
проверяет привязку progress к текущему lease worker в настоящем SQLite-репозитории.

Эти тесты подтверждают оркестрацию, но не качество распознавания, правила на реальных
трассах или полную готовность K4. Запуск: `uv run pytest tests/unit/pipeline -q`.
