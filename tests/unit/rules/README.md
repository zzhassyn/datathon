# `tests/unit/rules/` — тесты `rules`

> **Назначение:** Модульные тесты пакета `src/cashguard/pipeline/rules`: `<CODE>_test.py` на каждый код: pos/neg фикстуры из `tests/fixtures/timelines/`.
> **Владелец:** владелец правила · **Статус:** тесты числовых правил; обновлено 09.11.2026

`THIRD_PERSON_DURING_SERVICE_test.py` проверяет привязку начала сеанса к событию,
две сессии через разрыв, исчезновение людей и запрет объединять короткие
интервалы через разрыв. Входы полностью синтетические, без видео и моделей.

Также проверяются режимы `fixed`/`adaptive` и отсутствие настройки (по умолчанию
`adaptive`): узкие посетители, низкий фон, автоматический fallback,
масштаб, выброс высоты, длительность фонового трека, недостаточная уверенность
и опора, дубли ID/рамок, порядок детекций, зеркальный край двери и неизменность
входа. Маленький дубль не подавляет допустимую рамку, поздний уверенный участок
не подтверждает ранний после разрыва.
`test_temporal_rules.py` проверяет передачу режима без удаления людей из общей
сцены; `test_temporal_analysis.py` — ошибку анализа при неизвестном кассире.

Дополнительно проверяются перенос найденной роли из ручной калибровки,
согласованный разрыв при 1/2 fps, независимость масштаба от поздних посетителей
даже при постоянном фоне, поддержка подходящего трека при маленьком дубле,
округление PTS и реальные разрывы. Frozen-адаптер должен совпадать с числовым
путём, отклонять неоднозначные роли и неподдерживаемую геометрию зон.
