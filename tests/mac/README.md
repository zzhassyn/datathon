# `tests/mac/` — тесты только для Mac

> **Назначение:** Проверки, которым нужны Neural Engine, MLX и реальные модели. Маркер `mac`, на Windows пропускаются.
> **Владелец:** S3 (Core ML), S6 (MLX) · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Что планируется

| Что | Подробности |
|---|---|
| паритет Core ML | `.mlpackage` против `.pt` на отложенной сцене, разница ≤ 1 mAP50 |
| размещение на ANE | проверка MLComputePlan |
| офлайн-загрузка MLX | Qwen грузится при `HF_HUB_OFFLINE=1` |
| память | ≥ 3 ГБ свободно на ролике 145 с |
| `test_overlap_throughput.py` | ANE отдельно, GPU отдельно и вместе |
