## Документы

Symlink-сценарии пропускаются только при `WinError 1314` (нет привилегии Windows
на создание ссылки); остальные ошибки создания ссылки остаются падениями.
Проверка сессии и приватных файлов локальной модели выполняется отдельно от
symlink-сценария и не пропускается из-за этой привилегии.
