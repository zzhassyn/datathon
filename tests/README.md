# `tests/` — тесты Python

> **Назначение:** pytest-тесты сервиса. Шлюз мержа гоняет `pytest -m 'not mac and not slow'`.
> **Владелец:** по папкам · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `contract/` | [S0] замороженная схема жюри, дрейф OpenAPI, дословность цитат, полнота каталога |
| `api/` | [S1] HTTP-поведение API |
| `jobs/` | [S1] очередь и CAS |
| `workers/` | [S1] отказы воркеров |
| `unit/` | модульные тесты по пакетам |
| `mac/` | [S3/S6] только на Mac, маркер `mac` |
| `fixtures/` | таймлайны правил, пример ответа жюри, генератор синтетических видео |

## Правила

- Маркеры: `mac` — только на Mac, `slow` — долгие. Модели и датасет в обычных тестах не нужны.
- Тесты без доступа к сети.
- Как pytest различает одноимённые файлы в разных папках (`--import-mode=importlib` или уникальные имена) — решает S0 в `pyproject.toml` (проверить в P0).
