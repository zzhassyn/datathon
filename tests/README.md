# `tests/` — тесты Python

> **Назначение:** pytest-тесты сервиса. Шлюз мержа гоняет `pytest -m 'not mac and not slow'`.
> **Владелец:** по папкам · **Статус:** контрактные, API, модульные и интеграционные проверки реализованы; Mac/VLM-проверки ниже запланированы.

## Действующие тесты

| Файл | Что делает |
|---|---|
| `contract/` | [S0] замороженная схема жюри, дрейф OpenAPI, дословность цитат, полнота каталога |
| `api/` | [S1] HTTP-поведение API |
| `jobs/` | [S1] очередь и CAS |
| `workers/` | [S1] отказы воркеров |
| `unit/` | модульные тесты по пакетам |
| `fixtures/` | синтетические таймлайны правил, пример ответа жюри и эталонные ответы UI |

Запуск из корня: `uv run just test`; полный шлюз — `uv run just check`.
Синтетические видео создаёт [scripts/make_synthetic_mov.py](../scripts/make_synthetic_mov.py).

## Планируемые проверки

Папки создаются вместе с тестами; отдельные README-заглушки не хранятся.

| Область | План и владелец |
|---|---|
| `mac/` | [S3/S6] паритет Core ML и PT на отложенной сцене (цель — разница ≤ 1 mAP50), MLComputePlan/ANE, офлайн-загрузка MLX, ≥ 3 ГБ свободной памяти на ролике 145 с, пропускная способность ANE/GPU отдельно и вместе; маркер `mac` |
| `unit/evidence/` | [S3] выбор кадров, рамки и JPEG будущего общего evidence-пакета; текущая публикация проверяется API/render-тестами |
| `unit/vlm/` | [S6] группировка кандидатов, вопросы, схема ответов и выбор кванта на replay/null-бэкендах |

Эти пункты не являются результатами прогона. Контекст — [пайплайн](../docs/pipeline.md),
[обучение](../docs/training.md) и [Mac runbook](../docs/runbook_mac.md).

## Правила

- Маркеры: `mac` — только на Mac, `slow` — долгие. Модели и датасет в обычных тестах не нужны.
- Тесты без доступа к сети.
- Общие настройки pytest и маркеры — в `pyproject.toml`; имена тестовых модулей не должны конфликтовать при импорте.
