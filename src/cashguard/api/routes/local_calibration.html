Поверхность стола кассира

Кадр обрабатывается и показывается только на этом компьютере. Выделите мышью поверхность стола кассира. Исключите клиентский стол, стулья и проход. Координаты относятся к кадру после применения поворота. Само выделение ничего не сохраняет.

Загрузка локального стоп-кадра…

Нахождение вещи на столе или руки рядом не доказывает принадлежность сотруднику. Если принадлежность неизвестна, не включайте её подтверждение: итог правила останется заблокирован.

Для анализа событий выделите дополнительные зоны по очереди. Если выход или сейф не виден, оставьте эту зону пустой: соответствующее событие останется неизвестным.
