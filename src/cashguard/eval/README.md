# `src/cashguard/eval/` — оценка качества

> **Назначение:** Метрики по 40 обучающим роликам, LOSO, устойчивость, замеры скорости и симуляция жюри.
> **Владелец:** S1 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `labels.py` | чтение `analysis/labels_typed.csv`: нормализация X/Х, дубли Х-4/Х-47 и Х-5/Х-48 |
| `run_eval.py` | прогон сцены, правил и вердикта по трассам |
| `metrics.py` | recall и precision по видео, \|Δt\| медиана и p90, hit@1s/2s, точность типа, матрица ошибок |
| `loso.py` | фолды по сценам L1–L5 |
| `robustness.py` | hflip, поворот ±15°, crop-zoom, перспектива, гамма, 25 кадров/с |
| `perf.py` | проверка бюджетов этапов из `configs/perf_budget.yaml` |
| `jury_sim.py` | N параллельных загрузок через публичный URL, опрос раз в 3 с |
| `report.py` | отчёт в `var/eval/` и diff против `eval/baselines/main.json` |

## Правила

- Видео жюри и UI в оценку не попадают.
- `analysis/labels_typed.csv` только читается.
