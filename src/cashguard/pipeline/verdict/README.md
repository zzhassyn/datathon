# `src/cashguard/pipeline/verdict/` — вердикт

> **Назначение:** Баллы кандидатов, слияние, пороги и итоговый список нарушений.
> **Владелец:** S5 · **Статус:** 18.10.2026, `decide.py` реализован; качество на реальных трассах и подбор порогов ещё не проверены.

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `decide.py` | балл длительности, слияние, пороги, подавление, VLM и лучшие пять в порядке времени; замороженная сигнатура `decide(cands, review \| None, cfg)` |

Внутренний конфиг вердикта: `rules[CODE] = {enabled, tau, tau_final,
ref_duration_sec, suppresses}`, `vlm.scoring = {no_conf_min, down_factor}`.
Это проекция конфигов владельцев правил; `RuleConfig` и публичные схемы не менялись.
Код включается явно, `tau` обязателен; для интервала нужна `ref_duration_sec`.
Ни одного включённого настроенного правила → ошибка, а не чистый вердикт.
Параметры понижения VLM также задаются явно. Гиперпараметры ещё требуют LOSO/eval-full.

Слияние сохраняет лучший исходный балл и его якорь, объединяет интервал; разные
`track_id`/`session_id`/`vlm_group` не объединяются. Подавление требует заданного окна
и, при `same_track`, известного совпадающего трека. Циклическое подавление запрещено.
Shortlist и подавление фиксируются до VLM: исчезновение события не продвигает шестое.
`qid` равен ID кандидата, дополнительно совпадает `group_id` с `candidate.vlm_group`.
Пропущенный, неоднозначный или отсутствующий ответ сохраняет базовый порог; `tau_final`
применяется только после однозначного ответа. Повторные ответы считаются неоднозначными.

## Правила

- Вердикт `violation`, если после порога остался хотя бы один кандидат.
- Ответ VLM «нет» понижает балл и никогда его не повышает. Прошедший порог пониженный кандидат получает `downweighted`; отклонённые кандидаты сохраняются в `candidates.json`. Отдельное отображение отклонённых кандидатов текущим UI-контрактом этого среза не добавляется.
- τ подбирается по LOSO так, чтобы recall по видео был 1.0; результат без VLM — надмножество, безопасное для recall.
- Детерминированно: одинаковый вход → одинаковый выход. Только Python + numpy: модуль работает в режиме replay на Windows без моделей и Mac.
