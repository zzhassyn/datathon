# `src/cashguard/pipeline/verdict/` — вердикт

> **Назначение:** Баллы кандидатов, слияние, пороги и итоговый список нарушений.
> **Владелец:** S5 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `scoring.py` | балл = уверенность правила × фактор длительности |
| `aggregate.py` | слияние кандидатов одного кода в пределах 10 с; не больше 5 нарушений, по времени |
| `decide.py` | `verdict.decide(cands, review \| None, cfg) -> list[Decision]`; τ по коду; `vlm_status`: `confirmed`, `downweighted`, `unverified`, `skipped` |

## Правила

- Вердикт `violation`, если после порога остался хотя бы один кандидат.
- Ответ VLM «нет» понижает балл и никогда его не повышает; пониженный кандидат остаётся в UI с пометкой «снижено VLM».
- τ подбирается по LOSO так, чтобы recall по видео был 1.0; результат без VLM — надмножество, безопасное для recall.
- Детерминированно: одинаковый вход → одинаковый выход. Только Python + numpy: модуль работает в режиме replay на Windows без моделей и Mac.
