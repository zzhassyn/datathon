# `src/cashguard/pipeline/render/` — рендер результатов

> **Назначение:** Готовит `jury.json` по замороженной схеме и `ui_result.json` для интерфейса.
> **Владелец:** S1 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `jury.py` | `render.jury(result, evidence_dir) -> JuryJobResponse`: base64 JPEG без префикса (начинается с `/9j/`), 1–3 кадра, float с округлением 0,01, инвариант вердикта; проверка по `jury_job.schema.json`, при ошибке — безопасный fallback и повторная проверка |
| `ui.py` | `render.ui(result)` → фрагмент `UiJobView`: URL кадров вместо base64 |

## Правила

- Файлы пишутся атомарно (tmp → fsync → `os.replace`) до смены статуса в БД.
- Сигналы, заметки VLM и версии в `jury.json` не попадают.
- Fallback: перекодировать кадры, ограничить таймкоды [0, длительность], не больше 3 кадров, восстановить инвариант вердикта.
- Только Python + numpy: модуль работает в режиме replay на Windows без моделей и Mac.
