# `src/cashguard/pipeline/evidence/` — кадры-доказательства

> **Назначение:** Выбор, разметка и кодирование 1–3 кадров на нарушение из хранилища кадров.
> **Владелец:** S3 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `select.py` | кадр события на `timecode_sec`, увеличенный фрагмент ×3–4 вокруг бокса `EvidenceRequest`, контекст за 1,5 с до события |
| `draw.py` | рамки cv2 с ASCII-подписями |
| `jpeg.py` | JPEG q85 → `evidence/{i}_{event\|zoom\|context}.jpg` |

## Правила

- `evidence.render(decisions, store, out_dir) -> dict[str, list[EvidenceImage]]`.
- Кадры только из хранилища кадров, поэтому `timestamp_sec` — реальный PTS. Первый кадр совпадает с таймкодом нарушения.
- `Results.plot()` не использовать: он скачивает шрифт из сети.
- Тесты — `tests/unit/evidence/`.
