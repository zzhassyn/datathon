# `src/cashguard/pipeline/ingest/` — проверка файла и превью

> **Назначение:** Проверка контейнера и превью для браузера.
> **Владелец:** S1 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `probe.py` | PyAV: длительность, размеры, кодек, поворот. Лёгкая проверка в API ≤ 50 мс; глубокая в воркере: ≥ 1 видеопоток, 1–900 с, стороны ≤ 4096, первый кадр декодируется, иначе `UNSUPPORTED_VIDEO` |
| `preview.py` | remux в `preview.mp4` с `movflags=+faststart` без перекодирования (≤ 0,3 с); HEVC или поворот → `needs_transcode`, воркер перекодирует `h264_videotoolbox` |

## Правила

- Лёгкую проверку и remux выполняет и процесс API, поэтому из ML здесь можно только av. Не импортировать torch, ultralytics, coremltools, mlx, mlx_vlm, cv2 (проверяет import-linter в `uv run just check`). Как API подключает этот модуль при слоях `api → jobs → core → contracts` — решает S0 (проверить).
- Глубокая проверка — единственный штатный путь к статусу `failed`.
