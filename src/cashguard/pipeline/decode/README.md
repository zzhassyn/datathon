# `src/cashguard/pipeline/decode/` — декодирование и хранилище кадров

> **Назначение:** Декодирование PyAV по сетке PTS и запись сэмплированных кадров на диск (ADR-0011).
> **Владелец:** S3 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `pyav_source.py` | `VideoSource`: `thread_type='AUTO'`, сетка PTS (`t = frame.time − start`), BGR только для выбранных кадров, `frame.rotation`, очередь на 16 кадров |
| `frame_store.py` | `FrameStore`: JPEG q85 в `frames/{pts_ms}.jpg` + `frames/index.json`, отдельный поток записи |
| `window.py` | плотное повторное декодирование окна ±1 с для уточнения таймкода (P3, за флагом) |

## Правила

- Таймкоды только из PTS. `frame_index / fps` запрещено: ролики VFR, с B-кадрами и edit list.
- Кадры-доказательства и кадры для VLM берутся из хранилища, без seek.
- VideoToolbox hwaccel — только за флагом, по результату бенчмарка.
