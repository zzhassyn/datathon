# `src/cashguard/pipeline/vlm/prompts/` — промпты VLM

> **Назначение:** YAML-шаблоны промптов для проверки кандидатов и прохода по ключевым кадрам. Это данные, не Python-пакет.
> **Владелец:** S6 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `*.yaml` | шаблоны; вопросы на русском берутся из `vlm_question_ru` в `configs/catalog/<CODE>.yaml` |

## Правила

- В тексте промпта указываются таймстемпы кадров.
- Ответ — только по JSON-схеме из `schema.py`; свободный текст в описание для жюри не попадает.
