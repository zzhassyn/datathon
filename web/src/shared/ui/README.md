# Общие компоненты UI

Владелец: S2. Реализованы `Link` (переходы SPA с сохранением стандартных модификаторов), `ErrorBoundary`, `KeyGate` (опциональная cookie-сессия). Используются нативные элементы и локальные стили, без CDN. Компоненты shadcn из исходного плана не понадобились для текущего минималистичного интерфейса.

Тексты — `../i18n/ru.ts`. Данные доступа не сохраняются в URL/localStorage. Публичный API жюри не используется.
