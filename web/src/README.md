# `web/src/` — исходники SPA

> **Назначение:** React 19 SPA, собирается Vite в `web/dist` и раздаётся FastAPI с того же origin.
> **Владелец:** S2 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `main.tsx` | точка входа, провайдеры (TanStack Query, тосты) |
| `App.tsx` | выбор вида по `?job=<id>` и `?view=types`, без роутера |
| `pages/` | страницы |
| `features/` | функциональные блоки |
| `shared/` | API-клиент, UI-кит, утилиты, тексты |
| `styles/index.css` | Tailwind v4 |

## Правила

- Перед правкой прочитать `web/AGENTS.md`.
- TanStack Query — единственная библиотека состояния. react-router, msw, TypeScript 6/7 не ставить.
- Русские строки только в `shared/i18n/ru.ts`. Только системные шрифты, без CDN и аналитики.
