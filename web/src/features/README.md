# `web/src/features/` — функциональные блоки

> **Назначение:** Компоненты и хуки, сгруппированные по задачам пользователя.
> **Владелец:** S2 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `upload/` | загрузка с прогрессом и локальным превью |
| `progress/` | опрос задачи и этапы обработки |
| `verdict/` | итоговый вердикт |
| `violations/` | карточки нарушений с нормами |
| `evidence/` | кадры-доказательства и просмотр |
| `player/` | видео и шкала событий |
| `signals/` | наблюдения, не влияющие на вердикт |
| `recent/` | последние задачи |
| `health/` | индикатор готовности сервиса |

## Правила

- `KeyGate` нужен только при включённом `CG_UI_ACCESS_CODE` (по умолчанию выключен); место — на усмотрение S2.
