# `web/src/features/upload/` — загрузка

> **Назначение:** Блок «загрузка» интерфейса CashGuard.
> **Владелец:** S2 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Что планируется

| Что | Подробности |
|---|---|
| проверка файла | на клиенте: `.mov` или `.mp4`, ≤ 100 МБ, ошибки по-русски |
| загрузка через XHR | `POST /api/ui/jobs`: процент, МБ/с, оставшееся время, отмена, защита `beforeunload` |
| локальное превью | `URL.createObjectURL(file)`; при ошибке `<video>` — серверное превью |
