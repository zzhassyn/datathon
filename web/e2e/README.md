# `web/e2e/` — сквозные тесты

> **Назначение:** Playwright против FastAPI в stub-режиме; тот же набор можно прогнать против публичного URL.
> **Владелец:** S2; WebKit и iPhone на Mac запускает S6 · **Статус:** черновик v1, 17.10.2026 (каркас: кода ещё нет)

## Планируемые файлы

| Файл | Что делает |
|---|---|
| `upload.spec.ts` | загрузка, прогресс, ошибки размера и формата |
| `result.spec.ts` | вердикт, кадры, норма, переход по таймкоду |
| `mobile.spec.ts` | мобильная вёрстка |
| `fixtures/` | только синтетические ролики |

## Правила

- На Windows — канал `chrome` (кодеки H.264).
